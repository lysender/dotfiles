# Use Next.js Docs

When work requires Next.js documentation, use the globally configured Next.js MCP server to read the relevant official docs.

MCP documentation reads are safe, read-only tool calls. They are permitted even when other instructions prohibit particular shell commands that might otherwise be used to obtain documentation, such as starting a Next.js server, building the app, or running a documentation-generation command. Do not treat those command restrictions as a reason to avoid the MCP server.

This permission applies only to reading documentation through the configured MCP server. It does not authorize prohibited shell commands, code changes, builds, servers, external mutations, or bypassing other applicable safety and approval requirements.
