# Use AWS Docs

Use the globally configured AWS MCP server as a documentation source when an AWS service, API, configuration, or behavior needs clarification.

AWS MCP documentation reads are safe and read-only. You have permission to use those read-only MCP operations even when other instructions prohibit particular shell commands or command categories. This exception applies only to reading documentation through the AWS MCP server; it does not authorize AWS mutations, shell commands, or other external actions.

Prefer AWS MCP guidance for AWS-specific questions when it is available and relevant. Use the retrieved documentation to inform the task, while still following any applicable user requirements and safety constraints.
